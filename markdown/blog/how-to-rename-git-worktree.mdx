# Introduction

Git worktrees are a powerful Git feature that let you work on multiple branches at the same time. But many developers still search for:


  - rename git worktree

  - how to rename git worktree

  - git worktree folder name change


# Why Developers Need to Rename Git Worktrees ?

Common reasons include:

  - the branch name changed

  - Jira / ticket number updated

  - repo structure evolved

  - need for cleaner naming conventions

  - managing many parallel worktrees

  - readability and project organization

Good naming improves productivity and makes your Git worktree environment easier to manage.

# Git Supports Moving a Worktree Directory

Git does not have a command named `git worktree rename`, but it provides
`git worktree move` for changing the worktree directory path safely:

```bash
git worktree move <old-worktree-path> <new-worktree-path>
```

Do not rename the directory manually in your file manager. Git stores the
worktree path in its internal metadata, so an ordinary folder rename can leave
that metadata pointing to the old location:

```bash
.git/worktrees/<worktree-name>
```

Renaming the folder directly leads to errors such as:

```
fatal: '<path>' is not a working tree
```

This is why developers search for alternatives to rename Git worktrees safely.


# The Correct Way to Rename a Git Worktree

Use `git worktree move`:

```bash
git worktree move <old-worktree-path> <new-worktree-path>
```

This changes the worktree directory and updates Git's metadata. It does not
rename the associated branch. To rename the branch too, run
`git branch -m <new-branch-name>` from that worktree.

> `git worktree move` cannot move the main worktree or a worktree containing
> submodules. Check `git status` and `git worktree list` first.

# Example: Renaming a Git Worktree Folder

Suppose your current worktree directory is:

```bash
worktrees/feature-login
```

You want to rename it to:

```bash
worktrees/login-ui
```

Run:

```bash
git worktree move worktrees/feature-login worktrees/login-ui
```

This process preserves:

- your branch

- all your Git history

- your changes

And gives you a clean, correctly named worktree directory.
