# WorktreeWise Capabilities

## Worktree Management
Create, delete, move, lock, and unlock Git worktrees.

## Workflow Execution
Run commands across multiple worktrees in parallel or sequence.

## Hooks
Execute pre and post scripts when creating a worktree.

## IDE Integration
Open worktrees directly in JetBrains IDEs.

## Terminal Access
Open worktrees in terminal environments.
